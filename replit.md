# Catering Inventory Store Management System

## Project overview

This repository contains a Flutter application for catering inventory and store management. It includes inventory, purchasing, suppliers, recipes, waste, expiry, stock movement, multi-store, and reporting modules. The app currently uses local mock data and is designed to run across Flutter targets, including web.

## User preferences

- Preserve the existing Flutter project structure and visual language when adding features.
- Keep report experiences responsive and usable on mobile-sized screens.
